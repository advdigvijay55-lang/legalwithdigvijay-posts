# legalwithdigvijay-posts

Images and captions for the daily Legalwithdigvijay posts on Instagram (@legalwithdigvijay) and the Facebook Page "Advocate Digvijay Singh".

- `posts/YYYY-MM-DD/` — one folder per day: `post.json` (slides, caption, sources), `caption.txt`, and the carousel slides `01.jpg`, `02.jpg`, ...
- `tools/render.py` — renders `post.json` into 1080×1350 JPEG slides (`python3 tools/render.py posts/DATE/post.json posts/DATE`).

The repository is public because Instagram can only fetch post images from a public link.
